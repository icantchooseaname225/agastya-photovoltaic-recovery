# Material composition

Published module composition values are study-specific references, not assays of an AGASTYA panel. See the source evidence register and v3 scenario output. The 300 ppm review scenario has unresolved sample/denominator provenance; Dias et al.'s publisher abstract says 600 g/t, while a secondary conclusion excerpt says 630 g/t. These are separate reference bases, not a range and not AGASTYA measurements.
