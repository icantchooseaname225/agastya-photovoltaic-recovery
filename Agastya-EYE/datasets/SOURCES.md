# Candidate Dataset Notes

Reviewed 2026-09-26. Four version-pinned sources are imported for distinct tasks. Remaining entries are leads, not an instruction to mix every source into one classifier. Dataset labels, image modality, licensing, and grouping need to be checked before adding rows to `source_manifest.csv`.

Keep the original source attribution when distributing derivatives: Ashen Rodrigo, Isuru Munasinghe, Pubudu Sanjeewani, and Asanka Perera; based on `solarpaneldataset`.

The two Roboflow projects were not downloaded because their export endpoints require authenticated access. The Hugging Face model request also returned HTTP 401. No new weights or model training are claimed for these user-requested sources. Once an authorized export or accessible artifact is provided, record its version, archive hash, license, source panel grouping, label map, and split before training. Never combine EL, NIR, thermal, and RGB samples as though they came from the same sensor.

The source pages are mutable. Re-check licensing and class definitions at the time of download, preserve attribution, and keep it with processed images. The live RGB classifier only uses the imported full-panel RGB source above. Mendeley cell benchmarks and RaptorMaps thermal crops are separate research tasks; PV-Multi-Defect is a grayscale camera-crop research task with unspecified sensor band. Do not assume RGB transfer or pass these crops through the full-panel RGB model. New user RGB captures enter training only after an operator confirms the visual label in the app.
