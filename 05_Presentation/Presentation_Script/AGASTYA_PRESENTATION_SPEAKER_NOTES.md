## MASTER — Slide 6: An inspection and record tool—not a silver detector

Explain that EYE is a digital panel passport and inspection tool. It is not part of silver extraction chemistry and does not measure Ag. The project documents image capture, human-reviewed routing and optional low-voltage sensor records.
Evidence boundary: all literature values are study-specific. No AGASTYA physical recovery result is claimed.

## MASTER — Slide 7: Thermal delamination is a separate research thread

Older documents call the hot-knife process Stage 3; in the controlling current architecture it is optional pretreatment between Stage 1 and Stage 2. A 1-D five-node RC model was executed with explicit forward Euler time steps, using assumed literature properties and conditions. It generated historical virtual rows only. The solver does not model fracture, peel force, fume exposure, operator safety, machine power, actual heater energy per panel or separation quality. Do not present the displayed layer stack as apparatus.
Evidence boundary: all literature values are study-specific. No AGASTYA physical recovery result is claimed.
