|---|---|---|---|
| Liberation / size classification → flotation | Flotation is directly silver-specific in a published study on delaminated and ground c-Si cell feed. | R/U mass pull can be derived for that study's tap-water rougher point. | AGASTYA feed assay, PSD, liberation and matched-feed yield are unknown. |

| Dry size classification alone | Low-complexity feed-preparation comparator. | No Ag recovery is assigned; mass and Ag fractions are unknown. | Need size-by-size assay and downstream acceptance. |

The complete candidate sequence remains **mechanical liberation and size classification → conditional ECS → flotation**, with ECS bypass and alternative ordering available for matched-feed comparison. This preserves the owner's required research architecture while separating “candidate retained” from “performance demonstrated.” The simulation package quantifies only literature-derived flotation mass pull and the mathematical condition required for a three-operation route to match the direct-flotation reference. It does not rank routes economically or technically.

**Evidence labels:** the reported flotation response is literature-supported; the R/U mass pull and break-even equations are calculated; the parameter grid was simulated in Python; ECS integration is proposed; no route has been experimentally tested or validated by AGASTYA.
