## Objective

Define what Stage 4 can safely and credibly accept after the literature review found a mismatch between the thesis's expected feed and the Stage 3 output currently supported by evidence.

## Work completed

- Compared the Stage 3 baseline output (glass plus cell/EVA/backsheet laminate) with the thesis's Stage 4 assumption (EVA-stripped cell material containing liberated conductors).
- Recorded that the current Stage 3 output is not yet a valid ECS feed; the proposed EVA-removal roller is still unvalidated, and bound silver contacts are not the same as free conductive particles.
- Set a conservative first Stage 4 study objective: test measured enrichment of known, free aluminium/copper particles in a nonconductive reference mixture. This would validate only the separator method for that reference blend, not PV recovery.
- Defined minimum acceptance gates before any PV-derived feed: verified c-Si source, recorded upstream process, dry/contained sample, measured size and liberation state, complete stream collection and mass balance, suitable composition assay, and supervisor approval of the actual equipment and site controls.
- Defined operating variables, mass-closure/grade/recovery calculations and EYE traceability requirements in `../Build Files and Steps/Stage 4/STAGE4_FEED_REQUIREMENTS.md`.
- Prepared a blank Stage 4 trial-log CSV with feed identity, separator conditions, output masses, composition-assay provenance and result fields. The template contains headers only and no invented trial observations.
- Prepared a blank equipment-access inventory so existing or borrowable lab equipment can be checked before any procurement decision.

## Findings and limits

Stage 4 equipment cannot yet be selected or priced because no eligible PV feed specification, throughput, particle-size range, separator access, or assay method is established. EYE can preserve events for each panel after a Stage 3 completion, but a multi-panel batch also needs a separate source manifest linking panel IDs, Stage 3 outputs and Stage 4 run IDs.
