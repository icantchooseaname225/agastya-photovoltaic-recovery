## Maintenance rule

Create each future short entry together with its full entry. Match identifier and date, link both directions, preserve objective/findings/qualifications/decision/open questions/next action, cite supporting records, and label AI-assisted drafts or reconstructions clearly. Update the index in the same operation. Never backfill undocumented activity.
