# Stage 2 robotic disassembly

Current design direction: automated mechanical disassembly using a robotic arm as a tool-manipulation system, supported by an adjustable panel fixture. The robot is not assumed to lift a full module.

- [Feasibility review and decision gates](STAGE2_ROBOTIC_DISASSEMBLY_FEASIBILITY_2026-11-19.md)
- [Executed perimeter reach model](robot_workcell_reach_model.py)
- [Model outputs](simulation_outputs/model_report.md), including task-point CSV, JSON run record, and SVG reach diagram.
- [Concept workcell plan DXF and limits](simulation_outputs/concept_workcell_plan_notes.md), generated from the same 71-point screen.

No robot, fixture, or actuator has been selected or physically tested. The current model screens only planar radial reach under illustrative panel dimensions.
