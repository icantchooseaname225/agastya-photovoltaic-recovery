# Generated concept mesh exports

agastya_arm_envelope.obj is a nine-object, neutral-pose triangle mesh generated by generate_arm_obj.mjs. Its sibling MTL supplies display colors. agastya_arm_envelope.stl contains 556 triangles and is dimensioned in the source model in millimetres, although STL has no unit field.

The mesh is a visual envelope only. It has no manufacturing tolerances, material, wall thickness, fasteners, actuator interfaces, joints, motor models, cable route, tool, load ratings or safety clearances. No F3D or STEP was generated because the Fusion API script was not executed in the Fusion app.
